# GuardianTx — Phase 2 paper source

`main.tex` is a self-contained IEEEtran conference paper. It needs **no `.bib`
file** (the bibliography is embedded) and no extra packages beyond a standard TeX
distribution.

## Compile (easiest: Overleaf)
1. Go to overleaf.com → **New Project → Upload Project**, and upload `main.tex`
   (or drag the whole `docs/paper/` folder).
2. Overleaf picks `main.tex` automatically. Compiler = **pdfLaTeX** (default).
3. Click **Recompile** → download the PDF.

## Compile locally (if you have TeX Live / MiKTeX)
```bash
pdflatex main.tex
pdflatex main.tex   # run twice so cross-references and citations resolve
```

## Before you submit — 3 things to set (search `[SET` in main.tex)
1. **Project/group code** — in the `\title` footnote (e.g. `G3-xx`). Used in the
   submission filename `Phase2_<ProjectCode>_22I-0794_Paper.pdf`.
2. **Emails** — currently best-guess roll-number form (`i220794@nu.edu.pk`,
   `i220822@nu.edu.pk`). Replace with your real institutional emails.
3. **References** — every entry is a real paper/spec with a DOI or official URL,
   but re-check author lists and page numbers against each source PDF (the brief
   requires this), and confirm the arXiv-vs-proceedings venue you want to cite.

## Where the numbers come from
Every figure in the paper is from `results/*.json` and is regenerated by:
```bash
python data/build_corpus.py
python experiments/run.py all
python experiments/run.py e3 --planner llm --runs 3 --sample 12
```
Nothing in the paper is hand-entered that isn't in `results/`.
